# 0012 — Tracked validation is the last reviewed projection, not ambient local artifact state

- Date: 2026-08-08
- Status: accepted
- Deciders: project owner, SpecForge repository workflow

## Context

`VALIDATION_SNAPSHOT.md` is generated by `specforge project-validation`, but that producer is mutating:
it validates and rewrites every selected artifact, writes the git-ignored rescan plan, replaces the
tracked snapshot, and rewrites the live-status managed block. It is therefore unsafe to invoke as a
read-only doctrine check.

The tracked snapshot has remained byte-identical since reviewed commit `a44323d5`. Later canonical
promotion work deliberately did not refresh it because local git-ignored promotion results lacked the
required owner review. The current local artifacts demonstrate why that distinction matters: all four
selected IntentIR files carry zero embedded reports, and AHB's local sidecar is `8b5311ed…` / `63` while
the reviewed projection is `f2b3e059…` / `65`. Neither ambient local recency nor an unexplained old
Markdown file is sufficient validated-state authority.

## Decision

Define tracked validation currentness as exact agreement with a tracked, task-owned **reviewed
projection boundary**. The boundary declares the reviewed source commit; ordered artifact paths,
stages, report fingerprints, scores, grades, and finding counts; rescan/execution counts; relevant
producer regions; live-status markers and projection identity; and the review-gate evidence.

The currentness verifier is read-only. It authenticates the complete tracked snapshot, parses its
summary/recommendation/artifact semantics against the declaration, checks the live managed projection,
and hashes the exact producer regions that own refresh, rendering, and live-status replacement. It
never reads or mutates ambient git-ignored artifacts. Those artifacts may be newer, but they become
tracked validated state only through a separately reviewed refresh that updates the declaration and
all projections atomically.

## Consequences

- The tracked surface says “last reviewed” rather than “latest”, removing the time-layer ambiguity.
- CI and a fresh clone can prove the same reviewed boundary without host-local generated state.
- A producer-region, report identity, recommendation, snapshot, or live-projection change fails closed
  until one task-owned review updates the whole contract.
- This does not approve the current local artifact deltas, alter any validation score, or implement the
  deferred canonical-promotion approval workflow.
