# Prior Candidate Pages

This page family records review-only candidate prior surfaces.

It is for organizing which corpus-KB patterns might deserve typed `CorpusMemory` schema work, KG-bench coverage, validation gates, or bounded local-grounding consumers next.
It is not a `CorpusMemory` artifact, not an approval record, and not a canonical IR mutation path.

`kg-fixture-candidates.md` is the human-facing projection.
`kg-fixture-candidates.json` is the schema-versioned readiness manifest for review automation and future implementation planning.
Both remain non-promoting: readiness labels make fixture coverage easier to inspect, but they do not approve individual priors or write `generated/prior_memory/corpus_memory.json`.
